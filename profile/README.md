# Astra

Somos uma indústria brasileira que fabrica soluções em plástico para decoração, casa e construção civil. Nosso time de TI desenvolve aplicações para os sistemas e processos internos da empresa.

Este é o espaço da Astra no GitHub para apresentar os projetos que compartilhamos publicamente.

## Projetos

Explore a aba **Repositórios** para conhecer as iniciativas disponíveis. Em cada projeto, consulte o README para encontrar o contexto, as instruções de uso e as orientações para contribuição, quando houver.

## Conheça a Astra

Saiba mais sobre nossos produtos, nossa história e nossos canais de contato no [site oficial da Astra](https://www.astra-sa.com/).
